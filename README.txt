Project: Nova Studio — Responsive Design Landing Page

FILES
- index.html: page structure and navigation
- style.css: design and CSS media queries
- script.js: hamburger menu open/close behavior

HOW TO RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server or your browser.
4. Google Fonts requires an internet connection; the layout does not use any framework.

TASK REQUIREMENTS
- Responsive webpage using CSS media queries
- Mobile navigation collapses into a hamburger menu
- Desktop, tablet, and mobile layouts
- Accessible button state with aria-expanded

TESTING
- Desktop: navigation links appear across the top.
- Mobile (700px and below): tap the hamburger icon to open/close the menu.
- Resize the browser to test the responsive service cards and sections.
